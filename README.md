🎨 Canvas Drawing App

A modern HTML5 Canvas based drawing application built using Vanilla JavaScript, featuring smooth freehand drawing, shapes, undo/redo functionality, theme switching, and local auto-save support.

✨ Features
🖌 Drawing Tools

Freehand brush (smooth drawing)

Line tool

Rectangle tool

Circle tool

🎚 Brush Controls

Adjustable brush size

Floating brush size preview

Color picker

Color history palette

🔁 Undo / Redo

Unlimited undo support

Redo functionality using stack logic

🌓 UI & Experience

Dark / Light mode toggle

Responsive collapsible sidebar

Clean and modern UI

💾 Auto Save

Automatically saves drawing to localStorage

Drawing restored on page reload

🖼 Canvas

Built using HTML5 <canvas>

Optimized redraw using image snapshots

High performance drawing experience

🛠 Tech Stack

HTML5

CSS3

JavaScript (ES6)

HTML Canvas API

LocalStorage
